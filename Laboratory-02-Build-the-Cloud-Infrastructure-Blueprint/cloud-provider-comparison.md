# Cloud Provider Comparison

## Overview

The three major cloud service providers compared in this laboratory are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Each provider offers core infrastructure services for computing, storage, networking, and identity and access management.

## Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| **Compute** | Amazon EC2 provides virtual servers for running applications and workloads. | Azure Virtual Machines provide scalable virtual machines for applications and services. | Compute Engine provides configurable virtual machines for cloud workloads. |
| **Storage** | Amazon S3 provides object storage for storing and retrieving data. | Azure Blob Storage provides scalable object storage for cloud data. | Cloud Storage provides scalable object storage for data. |
| **Networking** | Amazon VPC provides virtual networking for AWS resources. | Azure Virtual Network provides private networking for Azure resources. | Google Cloud VPC provides networking for Google Cloud resources and workloads. |
| **Identity and Access Management (IAM)** | AWS IAM manages access to AWS resources using users, roles, policies, and permissions. | Microsoft Entra ID and Azure role-based access control help manage identities and access to Azure resources. | Google Cloud IAM manages access to resources through identities, roles, and permissions. |

## 1. Which cloud provider offers the broadest range of services?

AWS is widely recognized for offering a very broad range of cloud services across computing, storage, databases, networking, security, analytics, and other areas. Its large service portfolio makes it suitable for many different types of workloads and organizations.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that primarily uses Microsoft products. Azure integrates closely with Microsoft technologies and services, which can make identity management, application deployment, and administration more convenient for organizations already using the Microsoft ecosystem.

## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes services. Google Cloud provides services and technologies that support AI and ML workloads, while Google Kubernetes Engine (GKE) provides a managed Kubernetes environment.

## 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent core infrastructure services, including compute, storage, networking, and identity and access management. They also provide scalable cloud resources, security controls, and services that allow organizations to deploy and manage applications in cloud environments.
