# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity is the first mission in CCM101 – Cloud Computing. The activity introduces the basic responsibilities of a cloud infrastructure engineer, including working in a Linux environment, gathering system information, organizing files, documenting technical work, and preparing a GitHub portfolio.

## Objectives

- Access and use a cloud-based Linux environment through KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic Linux system information.
- Create and organize directories and files using Linux commands.
- Document technical work using Markdown.
- Prepare a professional GitHub repository for cloud computing laboratory activities.

## Activities Performed

1. Accessed an Ubuntu Linux environment through KillerCoda.
2. Verified the current username, working directory, and hostname.
3. Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
4. Created the Laboratory 01 workspace.
5. Created the `Notes` folder and `about-me.md` file.
6. Prepared screenshots as evidence of completed activities.

## Linux Commands Used

```bash
whoami
pwd
hostname
cat /etc/os-release
uname -r
lscpu
free -h
df -h /
mkdir -p
ls -la
cat
nano
```

## Skills Learned

Through this activity, I learned how to work with a cloud-based Linux environment, navigate directories, create files and folders, gather system information, and document technical activities using Markdown. I also learned the importance of keeping organized evidence and maintaining a professional cloud computing portfolio.
