# Reflection

## My Experience

This laboratory activity gave me my first hands-on experience working with a cloud-based Linux environment through KillerCoda. I learned how to navigate the Linux terminal, check system information, and organize files and directories using Linux commands.

## What I Learned

I learned how commands such as `whoami`, `pwd`, `hostname`, `lscpu`, `free`, `df`, `mkdir`, `ls`, and `cat` can be used to manage and investigate a Linux environment. I also learned how Markdown can be used to document technical information in an organized and readable format.

## Challenges Encountered

One challenge I encountered was becoming familiar with the Linux terminal and making sure that files were created in the correct directories. I also learned that small mistakes in commands can affect files, so it is important to carefully check commands before executing them.

## Overall Reflection

This activity helped me understand the importance of Linux skills, organization, documentation, and version control in cloud computing. I believe the skills I practiced in this laboratory will be useful in the succeeding cloud computing activities throughout the semester.
