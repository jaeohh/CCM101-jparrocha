# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

This laboratory focused on deploying an S3-compatible object storage server using MinIO and Docker. The activity also involved comparing different types of cloud storage and using object storage for a client photo-sharing application.

## Objectives

- Compare Block Storage, File Storage, and Object Storage.
- Understand why Object Storage is suitable for user-uploaded images.
- Deploy MinIO using Docker.
- Access the MinIO web console.
- Create a bucket named `client-photos`.
- Upload a sample file to the bucket.
- Document the deployment process.
- Reflect on the skills learned during the activity.

## Tools Used

- KillerCoda Ubuntu
- Docker
- MinIO
- Web browser
- GitHub
- Linux command line

## Skills Learned

- Comparing different cloud storage types.
- Using Docker to deploy a storage service.
- Working with MinIO as an S3-compatible object storage platform.
- Creating and managing an object storage bucket.
- Uploading objects through a web console.
- Using Linux command-line commands to manage and verify a deployment.
- Documenting cloud infrastructure deployment steps.
