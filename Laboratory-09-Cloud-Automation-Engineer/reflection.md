# Laboratory 09: Mission Reflection

Throughout Laboratories 1 to 9, my understanding of cloud computing has developed from learning basic Linux commands to understanding how infrastructure, applications, security, and automation work together. At first, I focused on exploring the cloud environment and documenting system information. As I completed more activities, I gained experience with cloud platforms, GitHub, application deployment, system operations, and firewall configuration.

Automation is critical when managing hundreds of cloud servers because performing the same task manually on every server takes time and increases the chance of human error. Bash scripts and Cron jobs can help administrators perform repetitive tasks consistently, such as creating scheduled backups. This laboratory helped me understand how automation can reduce manual work and make routine server administration more efficient.

However, automation also has risks. A destructive typo in a script scheduled to run on 1,000 servers could affect many systems before an administrator notices the problem. For this reason, scripts should be reviewed, tested in a safe environment, and monitored before they are deployed widely. Automation should improve reliability, not remove the need for careful supervision.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash uses commands and variables to perform actions in sequence, while Docker Compose YAML describes the services and configuration of an application environment. Both tools reduce repetitive work, but they solve different problems.

Among the roles I explored, I enjoyed the **Cloud Security Engineer** role because it showed me how firewall rules and restricted network access help protect systems. The automation activity also helped me see why security and reliable operations must work together.

Overall, this portfolio represents my progress from basic cloud exploration to practical infrastructure management. I still have more to learn, but I am becoming more confident in using Linux commands, documenting technical work, and understanding how cloud systems are managed.
