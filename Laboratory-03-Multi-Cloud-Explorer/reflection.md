# Checkpoint 8 — Reflection

## My Reflection

Among the three major cloud platforms, Google Cloud Platform (GCP) impressed me the most. I found its focus on artificial intelligence, machine learning, data analytics, and Kubernetes interesting. Services such as Vertex AI, Compute Engine, and Google Kubernetes Engine showed me how cloud platforms can support both traditional applications and modern technologies.

AWS, Azure, and GCP have many similarities. All three provide computing, storage, networking, databases, identity and access management, security, and scalability services. They also allow organizations to deploy applications without having to maintain all of the physical infrastructure themselves. However, each platform has different strengths and services that may make one provider more suitable for a particular organization.

Business requirements strongly influence cloud platform selection. Factors such as budget, existing technologies, workload requirements, scalability, security, location, and technical skills must be considered. For example, Azure is a strong choice for an organization already using Microsoft technologies, while GCP can be a good option for AI and machine learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The decision should be based on the client's actual needs and the services that can best support their goals. Comparing different providers helped me understand how technical requirements can be connected to business objectives.

Building my GitHub portfolio also improved my learning because it allowed me to organize my laboratory activities and document my progress. Using Git and GitHub helped me understand version control, collaboration, and the importance of keeping technical work organized. This activity also gave me more confidence in researching and comparing cloud technologies.
