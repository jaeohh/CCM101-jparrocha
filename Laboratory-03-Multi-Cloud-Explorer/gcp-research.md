# Google Cloud (GCP) Research

## 1. Brief Overview

Google Cloud is Google's public cloud computing platform. It provides services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, security, and application development. Google Cloud allows organizations to build and operate applications using Google's global infrastructure.

## 2. Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Regions are independent geographic areas, while zones are isolated locations within regions. Organizations can distribute resources across regions and zones to improve availability, reduce latency, and provide protection against infrastructure failures.

Google Cloud also operates a global network designed to provide high-performance connectivity for applications and users around the world.

## 3. Cloud Management Console

The Google Cloud console is a web-based management interface for creating, configuring, monitoring, and managing Google Cloud resources. It provides access to services, projects, billing, monitoring, security, networking, and other cloud management functions.

## 4. Four Core Services

### Compute Engine

Compute Engine provides virtual machines that run on Google's infrastructure. Organizations can use virtual machines to host applications, websites, and other workloads.

### Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data such as files, backups, media, and application data.

### Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities for cloud resources. It allows organizations to configure networks, subnets, routes, firewall rules, and connectivity between resources.

### Cloud IAM

Cloud Identity and Access Management (IAM) provides permissions management for Google Cloud resources. It allows organizations to control which users and service accounts can access specific resources and what actions they can perform.

## 5. Three Advantages

1. **Strong AI and Machine Learning Capabilities** – Google Cloud provides a wide range of AI and machine learning services and infrastructure.
2. **Global Network** – Google Cloud uses Google's global network infrastructure to provide connectivity and support applications deployed around the world.
3. **Data and Analytics** – Google Cloud provides strong services for data processing, analytics, databases, and large-scale workloads.

## 6. Typical Enterprise Use Cases

Google Cloud is used for application hosting, data analytics, artificial intelligence and machine learning, containerized applications, databases, storage, and large-scale data processing.

Organizations can combine services such as Compute Engine, Cloud Storage, VPC, and Cloud IAM to create secure and scalable cloud environments.
