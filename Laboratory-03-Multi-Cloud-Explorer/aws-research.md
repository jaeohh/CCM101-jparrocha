# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform launched by Amazon in 2006. It provides a broad range of cloud services, including computing, storage, databases, networking, security, analytics, and developer tools. AWS uses a pay-as-you-go model, allowing organizations to provision resources without purchasing and maintaining physical infrastructure.

## 2. Global Infrastructure

AWS operates a global infrastructure made up of Regions and Availability Zones. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. Using multiple Availability Zones can help organizations design highly available applications and reduce the impact of infrastructure failures.

AWS also provides additional infrastructure options such as Local Zones and Wavelength Zones for applications that require resources closer to end users or very low latency.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can launch resources, configure services, monitor workloads, manage security, and select AWS Regions through the console.

## 4. Four Core Services

### Amazon EC2
Amazon Elastic Compute Cloud (EC2) provides resizable virtual computing capacity in the AWS Cloud. Organizations can use EC2 instances to host applications, websites, and other workloads.

### Amazon S3
Amazon Simple Storage Service (S3) provides object storage for storing and retrieving data such as documents, images, backups, and application files.

### Amazon VPC
Amazon Virtual Private Cloud (VPC) allows organizations to create logically isolated networks in AWS and control networking resources such as subnets, routing, and security.

### AWS IAM
AWS Identity and Access Management (IAM) helps organizations control access to AWS resources by managing users, roles, and permissions.

## 5. Three Advantages

1. **Scalability** – AWS allows organizations to increase or decrease computing and storage resources according to demand.
2. **Global Reach** – AWS provides infrastructure in many geographic regions, allowing applications to be deployed closer to customers around the world.
3. **Pay-as-you-go Model** – Organizations can pay for the resources they use instead of making large upfront investments in physical infrastructure.

## 6. Typical Enterprise Use Cases

AWS is used by startups, enterprises, government organizations, and other organizations for many types of workloads. Common examples include web and mobile applications, data processing, databases, storage and backup, application development, and enterprise software.

Organizations can combine AWS services such as EC2, S3, VPC, and IAM to build secure, scalable, and highly available cloud applications.
