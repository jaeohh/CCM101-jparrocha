# Azure Research

## 1. Brief Overview

Microsoft Azure is a public cloud computing platform created by Microsoft. It provides cloud services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development. Azure supports organizations in building, deploying, and managing applications through Microsoft's global cloud infrastructure.

## 2. Global Infrastructure

Azure operates through a global network of regions and datacenters. Azure regions are geographic areas that contain datacenters where cloud services and resources can be deployed. Azure also provides availability zones in supported regions to help applications remain available if a datacenter experiences a failure.

Azure's global infrastructure allows organizations to deploy applications closer to their customers and create solutions that support high availability and business continuity.

## 3. Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Administrators can use the portal to manage virtual machines, storage accounts, databases, networking resources, identities, and other cloud services.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide scalable virtual servers in the cloud. Organizations can use them to run Windows or Linux operating systems and host applications and services.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data such as documents, images, videos, backups, and application data.

### Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure. It provides networking capabilities such as subnets, routing, and connectivity between cloud resources.

### Microsoft Entra ID

Microsoft Entra ID, formerly known as Azure Active Directory, is Microsoft's cloud-based identity and access management service. It helps organizations manage users, applications, devices, and access to cloud resources.

## 5. Three Advantages

1. **Microsoft Integration** – Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, and other enterprise products.
2. **Global Infrastructure** – Azure provides regions and datacenters around the world, allowing organizations to deploy applications close to their users.
3. **Enterprise Capabilities** – Azure provides a wide range of services for security, identity, networking, databases, analytics, and application development.

## 6. Typical Enterprise Use Cases

Azure is widely used by organizations for application hosting, enterprise systems, databases, data analytics, artificial intelligence, backup and disaster recovery, and hybrid cloud solutions.

Organizations can combine services such as Azure Virtual Machines, Blob Storage, Virtual Network, and Microsoft Entra ID to create secure and scalable cloud environments.
